Суб-агенты этого проекта. Знают его стек, команды и домен — в отличие от
глобальных в `~/.claude/agents/` (`project-scout`, `spec-writer`, `session-scribe`).

Заводи проектного агента, когда задача повторяется и требует контекста проекта:
миграции конкретной БД, деплой, парсер конкретного API, прогон бэктестов.

Формат — markdown с frontmatter:

```markdown
---
name: db-migrator
description: Когда звать этого агента.
tools: Bash, Read, Edit, Write, Grep, Glob
---

Системный промпт: что агент делает, в каком порядке, что возвращает,
чего не трогает.
```
