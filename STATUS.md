# STATUS — teremok

Обновлено: 2026-09-05

## Что это

Учёт телеком-стройки на **teremok.live** (старая доска объявлений снесена).
Спека — `spec/crm.md`. Код в корне репозитория `raccoontower/teremok`,
Vercel деплоит `main` сам.

## Работает

- **База** — Supabase, схема применена: `sites, partners, workers, expenses,
  payroll, income, schedule` и представление `site_totals`, где прибыль
  считается **без** `reimbursable` — деньги за Home Depot вернёт GC, это не
  наш расход. Проверено: покупка 198.01 легла в reimbursable, прибыль 0.
- **Ввод по фото чека** — `POST /api/receipt`: Gemini вытаскивает магазин,
  итог после налога, дату, позиции; вид расхода предлагается по магазину.
- **Сохранение** — `POST /api/expenses` с чеком в приватный бакет `receipts`.
- **Объекты** — `/sites`, форма из трёх полей.
- Экраны: `/` (заглушки цифр), `/add`, `/sites`.

## Подключения

- Ключи: `~/projects/env/teremok.env` (URL, publishable, secret, пароль базы).
- К базе с коробки — только через пулер: прямое подключение у Supabase
  по IPv6, которого здесь нет. Рабочий: `aws-0-us-west-2.pooler.supabase.com:6543`,
  пользователь `postgres.<ref>`. Регион базы — Oregon, не East.
- Миграции: `.venv-db/bin/python` + psycopg, файлы в `supabase/migrations/`.
- Репозиторий: deploy key `~/.ssh/teremok_deploy`, хост-алиас `github-teremok`.

## Не сделано

- **Переменные в Vercel** — без них прод не работает: `SUPABASE_URL`,
  `SUPABASE_SECRET_KEY`, `GEMINI_API_KEY`. Ставит владелец.
- Цифры на главной, срезы по вышке и месяцу, бригада и зарплаты,
  расписание, делёж с партнёром, отчёт GC с чеками, ручная форма для Amazon
  и билетов. Порядок — в спеке.
- Доступ: приложение открыто всем, кто знает адрес. Нужен вход (двое
  партнёров + бригадир) до того, как там появятся реальные суммы.
